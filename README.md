# veronicasaron.com

Veronica Saron's personal site. Plain HTML with no build step.

- `index.html` is the main site with all three modes.
- `for-ai.html` and `llms.txt` are the facts pages for AI agents and search engines. Update them whenever the main site's facts change.
- `img/` holds every image.

To edit, change a file on GitHub and commit it. Cloudflare Pages republishes the site in about a minute.
